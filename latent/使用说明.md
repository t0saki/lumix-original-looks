# 潜影 Latent · Lumix S9 机内 LUT 套装（12 支）

全部为 sRGB→sRGB、33 点 `.cube`，头部带 `#LUMIXPHOTOSTYLE STD`，叠在 **Standard** 照片风格上使用。文件名 ≤8 位，直接拷入 SD 卡的 `LUT` 文件夹后在相机里读取。
本套的共同底线：白永远是白（近白处不染色），黑位扎实不发灰，肤色明亮通透，性格来自彩色内部的结构（色相各向异性、色度门控、色度拱形、冷暖亮度分离），不是灰轴染色。
**100% 就是完整风格**；机内百分比是给场景不合时用的减法。

## 上机检查清单（约 40 分钟，只有你能做）
1. 同一静物场景（人脸 + 白衬衫 + 灰卡 + 天空）：无 LUT / 某支 100% / 同支 70%，RAW+JPG 各拍一张——用来验证机内强度是线性混合的假设。
2. ISO 6400 暗混合光一张（有/无 LUT）：放大看暗部，**出现无 LUT 帧里没有的彩色斑块 = 不合格**，告诉我是哪支。
3. 金光逆光人脸：脸是否发橙、发塑料。
4. 白墙 / 阴天高调：近白是否偏色；**EVF 里**看天空是否有断层（EVF 最先露馅）。
5. 真正的裁决：装两三支拍一天，你最后把哪支留在相机里——这个答案高于本文件里的一切数字。

## 曝光与稳健性（P5 对抗测试的结论）
安全曝光区间 = 相对正常曝光，3% 像素开始出现额外黑/白裁切之前能承受的欠/过曝（±3.0+ 表示测到 ±3 EV 仍无问题）。噪声放大 = ISO 12800 下 LUT 对噪声的放大倍数（<1 表示反而压噪）。白平衡稳健性 = 色温/色调偏移下的色相反转角度与裁切增量。易混淆 = 70% 强度下在 14 个场景里与最接近的另一支的可辨余量（dE00，负值 = 有场景分不清）。白平衡扰动下的暗部裁切增量门槛最终定为 1.5%（04Viride 在暖色温/偏绿色调下最高 1.31%，08Arcade 0.95%，均通过）。

## 每支的已知短板（对抗测试与盲评里看到的，按需回避）
- `10Splice`：钨丝灯/荧光灯下的人脸会出现"受光面偏奶白、背光面偏红棕"的分裂，欠曝超过 −0.7 EV 暗部即压死；建议用于城市、蓝调时刻、剧照感的环境，夜景人像慎用。
- `04Viride`：夜景里红色霓虹会偏品红、雾霾夜空偏紫——它是白天的风景片，夜景请换 Sodium。
- `08Arcade`：品红中调是它的性格，白色室内墙面在 100% 下会带一丝淡紫（已收敛到 ≈2–3 码），介意就用 75–85%。
- `09Tinsel` / `01Glaze`：钨丝灯下受光皮肤略偏奶油、阴影保持橙——轻微，属于胶片式高光去饱和。
- `03Gilt`：夜景暗部深，已开趾（0–12% 平均斜率 0.58），仍建议 +0.3 EV 起拍。
- `12Argent`：太阳附近的过曝区比彩色片更大一点（黑白肩部更硬）。
- 区分度：`03Gilt` 与 `04Viride` 在天空上很接近（各自的差别在中性物与绿叶）；`05Clear` 与 `06Almond` 在人像上接近（差别在影调与环境色）。

## 已知限制
- LUT 是逐像素映射：颗粒、光晕、柔焦、暗角、局部反差都做不到。
- 机内强度混合模型 `s·LUT(x)+(1−s)·x` 未经机内验证；70% 的效果以实拍为准。
- 基底是用 290 对 RW2/机内 JPG 校准的 LibRaw 显影，与真机内 Standard 的平均色差约 1.5 dE00；高 ISO 混合光下会更大一些。
